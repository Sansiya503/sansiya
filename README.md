# 산시야

건축·인테리어·조경·도시·공간디자인·AI·게임·주식·과학기술 등 관심 분야의 스크랩과 취향을 기록하는 나만의 아카이브 앱이에요.
폰(안드로이드)과 컴퓨터에서 같은 기록을 보고, 인터넷이 끊겨도 읽고 쓸 수 있어요.

- 앱 주소: https://sansiya503.github.io/sansiya/
- 기록 저장: Supabase 프로젝트 `sansiya` (서울, 무료 플랜) — 로그인한 본인만 읽고 쓸 수 있어요
- 새 가입은 막혀 있어요. 계정은 Supabase 대시보드 → Authentication → Users에서 관리해요.

## 주식 메뉴

- **내 주식:** 보유 수량과 평균 단가를 넣으면 평가금액·수익률을 자동 계산해요. 국내/해외로 나눠 보여 주고, 평가금순·수익률순·이름순 정렬과 평가금/현재가 보기를 고를 수 있어요. ‘금액 숨기기’를 누르면 수익률만 보여요.
- **관심:** 현재가, 어제보다 등락률, 목표가까지 남은 거리를 보여 줘요.
- **배당:** 받은 배당을 기록하면 연도별·월별로 모아 보여 줘요. 달러 배당은 원화로 환산해요.
- **종목 상세:** 1일·1주·1달·3달·1년·5년 차트, 내 주식, 목표가, 메모, 날짜별 노트, 배당 내역.
- **시세:** Supabase Edge Function `quotes`가 Yahoo Finance 차트 데이터(비공식, 한국 종목은 약 20분 지연)에서 가져와요. 한국 종목 한글 검색은 aikstockdata.com(금융위원회 공공데이터, 비상업적 이용·출처 표시)을 써요. 소스는 `supabase/functions/quotes/index.ts`, 테이블은 `supabase/stocks.sql`.

## 안드로이드 폰에 설치하기

1. 폰의 **Chrome**으로 앱 주소를 열고 로그인
2. 오른쪽 위 **⋮** → **앱 설치**(또는 **홈 화면에 추가**)
3. 홈 화면의 산시야 아이콘으로 열면 앱처럼 전체 화면으로 실행돼요.

## 쓰면서 알아 둘 것

- **오프라인:** 인터넷이 없어도 기록을 보고 쓰고 고칠 수 있어요. 상단에 "대기 N건"이 보이면 연결되는 순간 자동으로 올라가요. 사진 올리기만 인터넷이 필요해요.
- **백업:** 설정 → JSON 내보내기로 가끔 백업해 두세요. (사진은 Supabase에 따로 보관돼요.)
- **Supabase 무료 플랜 일시정지:** 7일 동안 사용이 거의 없으면 프로젝트가 일시정지돼요. 앱에서 "Supabase에 연결하지 못했어요"가 나오면 대시보드에서 프로젝트를 열고 **Resume project**를 누르세요. 데이터는 그대로예요.
- **비밀번호를 잊었을 때:** 로그인 화면에서 이메일을 적고 **비밀번호를 잊으셨나요?**를 누르면 재설정 메일이 와요. 메일의 링크를 누르면 앱에서 새 비밀번호를 정할 수 있어요. 로그인한 상태에서는 설정 → 비밀번호 바꾸기.

## 앱 수정하기

1. 바꾼 파일을 이 저장소에 같은 이름으로 다시 올리세요 (Add file → Upload files, 덮어쓰기).
2. **`sw.js` 맨 위의 `VERSION` 숫자를 올려야** 폰에 새 버전이 적용돼요. (예: `sansiya-v1.0.0` → `sansiya-v1.0.1`)
3. 폰에서 앱을 다시 열면 "새 버전이 준비됐어요 · 적용"이 떠요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 뼈대 |
| `styles.css` | 디자인 (색, 글꼴, 배치) |
| `app.js` | 기능 전부 (기록, 동기화, 캘린더, 통계, 백업) |
| `config.js` | Supabase 연결 정보 (공개돼도 괜찮은 키) |
| `sw.js` | 오프라인 동작, 업데이트 |
| `manifest.webmanifest` | 앱 이름·아이콘 (설치용) |
| `*.png`, `favicon.svg` | 앱 아이콘 |
| `setup.sql` | Supabase 테이블·보안 설정 (이미 적용됨, 다시 만들 때만 필요) |

## 나중에 플레이스토어에 올리려면

이 앱은 PWA라서 [PWABuilder](https://www.pwabuilder.com/)로 안드로이드 패키지(TWA)를 만들거나,
Capacitor로 감싸서 Google Play에 올릴 수 있어요. 다른 사람도 쓰게 하려면 회원가입, 개인정보처리방침,
계정 삭제 기능을 추가해야 해요.
