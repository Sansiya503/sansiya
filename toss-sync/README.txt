산시야 · 토스증권 연동 (조회 전용)

토스증권 계좌의 보유 종목·수량·평균 단가를 30분마다 읽어 산시야 '내 주식'에 맞춰요.
주문(매수·매도)은 하지 않아요.

[처음 설치]
1. 산시야 앱 → 설정 → 토스증권 연동 → '연결 코드 만들기'를 누르고 코드를 복사해 두세요.
2. 토스증권 PC 웹(WTS) → 설정 → Open API에서 키(client_id, client_secret)를 발급하세요.
3. 1-install.cmd 를 더블클릭하세요. 화면에 나오는 이 컴퓨터의 IP를
   토스증권 PC 웹 → 설정 → Open API → 아래쪽 '허용 IP 관리'에 등록하세요.
4. 설치 화면에 client_id, client_secret, 연결 코드를 차례로 붙여넣으면 끝이에요.
   (Windows가 '알 수 없는 앱' 경고를 띄우면 '추가 정보' → '실행'을 누르세요.)

[파일]
1-install.cmd    설치 (키 입력, 첫 동기화, 30분마다 자동 실행 등록)
2-sync-now.cmd   지금 바로 한 번 맞추기
3-turn-off.cmd   연동 끄기 (자동 실행과 이 컴퓨터에 저장한 키를 지워요)

[알아 둘 것]
- 토스 키는 이 컴퓨터의 Windows 계정에서만 풀리게 암호화해서
  %LOCALAPPDATA%\Sansiya\TossSync 에 저장해요. 산시야 서버로는 보내지 않아요.
- 자동 실행은 Windows '작업 스케줄러'의 'Sansiya Toss Sync' 작업이에요.
- 컴퓨터가 꺼져 있으면 맞추지 않고, 다음에 켜졌을 때 맞춰요.
- 공유기를 다시 켜는 등으로 IP가 바뀌면 앱 설정에 안내가 떠요. 새 IP를 토스에 등록하면 돼요.
- 기록: %LOCALAPPDATA%\Sansiya\TossSync\sync.log
